## \# SQL Practice Starter Pack

# 

Este repositório é um \*\*pacote centralizado de estudos e práticas com banco de dados\*\*, criado para evitar a fragmentação em múltiplos repositórios com o mesmo propósito.



Aqui estão armazenados \*\*dumps de bancos de dados\*\* utilizados em exercícios práticos, testes de modelagem, consultas SQL, relacionamentos e simulações de cenários reais.


&nbsp;- Dentro de cada banco, os dumps são organizados por data de criação



&nbsp;- Cada dump representa um estado específico do banco naquele momento do estudo



#### 🎯 Objetivo



###### &nbsp;Praticar SQL na prática, não apenas teoria


&nbsp;\* Trabalhar com:



&nbsp;\* Modelagem relacional

&nbsp;

&nbsp;\* Chaves primárias e estrangeiras


&nbsp;\* JOINs



&nbsp;\* Consultas complexas



&nbsp;- Refatoração de schema



&nbsp;- Simular evolução real de banco de dados ao longo do tempo



&nbsp;- Este repositório não é um projeto final, mas um ambiente de aprendizado contínuo

# 

#### 📌 Observações



Os dumps não seguem uma progressão linear obrigatória.



Cada banco pode ter sido usado para testar conceitos diferentes.



Erros fazem parte do processo e alguns dumps existem justamente para análise e correção.
